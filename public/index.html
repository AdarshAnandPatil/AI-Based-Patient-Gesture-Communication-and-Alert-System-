Live Verification Checklist

  2. Confirm detected text, voice and alert include Patient ID, Room and Bed.
  3. Repeat in English, ಕನ್ನಡ and हिन्दी.
  4. Start Face & Eye AI → verify face appears.
  5. Test blink and head movement one at a time.
  6. Open Alert Center and confirm new alerts are visible.

● Recommended for remote monitoring

Same Wi‑Fi Connection

If the patient computer and phone are on the same Wi‑Fi, enter the computer's local IP in the mobile app.

http://COMPUTER-IP:10000

Example: http://192.168.1.10:10000

How the mobile app works

1Install/run the Flutter Android app.
2Open Settings and enter the Render URL or computer IP.
3The app checks the server every 2 seconds for new alerts.
4New alerts are displayed and spoken aloud.

Important: the Flutter folder is Android app source code. It must be built into an APK with Flutter/Android Studio before it can be installed as a native app.
