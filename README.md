# AI Based Healthcare System — Master Project Specification

This ZIP contains the complete master development prompt for the integrated AI healthcare project.

## Core differentiator

AI hand-gesture communication for patients, connected to nurse/doctor web dashboards and a companion mobile application.

## Required languages

- English
- Kannada (ಕನ್ನಡ)
- Hindi (हिन्दी)

Voice alerts, push notifications and patient confirmations should use the selected language where technically supported.

## Recommended build order

1. Authentication/RBAC
2. Database and backend APIs
3. Hand gesture detection
4. Gesture-to-message workflow
5. Nurse web alerts
6. Mobile push notifications
7. Multilingual text + voice
8. Acknowledgement/escalation
9. AI risk/triage
10. Medical report OCR/analysis
11. Doctor assistant
12. Queue/waiting prediction
13. Bed management/forecasting
14. Analytics, audit logs and testing

## Important

This is an academic decision-support prototype. It must not claim to diagnose, prescribe, or replace qualified healthcare professionals.

See `MASTER_PROJECT_PROMPT.md` for the complete specification.
