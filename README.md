# Engineering Student Portal

A student learning and placement-preparation portal with a colorful responsive UI.

## Run

```bash
npm start
```

Open `http://localhost:3000`.

## Render

- Build command: leave empty
- Start command: `npm start`
- Node: 18+

## Demo admin

Email: `admin@college.com`

Change the credentials/authentication before production use.

## Main sections

Home, E-Library, Results, Placements & Internships, Technical Skills & Resources, Aptitude, Communication & English, Interview Preparation, AI Career Mentor, Job Preparation Roadmap, Free Courses & Certifications, Resume Builder, Project Ideas, Daily Practice, Announcements, Academic Calendar and Useful Links.

Coding Practice is not a separate top-level menu; coding practice remains available through Technical Skills, Placement Questions and Daily Practice.

Internships are listed under Job Alerts together with jobs.

Placement Experiences is intentionally not included.
