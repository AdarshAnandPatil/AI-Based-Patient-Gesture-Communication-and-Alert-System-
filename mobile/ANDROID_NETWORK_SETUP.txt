ANDROID NETWORK SETUP FOR LOCAL COMPUTER IP

After running `flutter create .` in this mobile folder, edit:
android/app/src/main/AndroidManifest.xml

Inside the <manifest> element add:
<uses-permission android:name="android.permission.INTERNET" />

On the <application ...> element add:
android:usesCleartextTraffic="true"

This is required when the phone connects to a local computer using:
http://192.168.x.x:10000

For the Render HTTPS URL, cleartext is not required.
